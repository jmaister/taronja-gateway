Taronja Gateway — Docker Demo

This page itself is a static route: the gateway is serving these files directly from disk (static: true, toFolder), with a 1-hour Cache-Control header — check the response headers on this request.

Routes to try

  • /second_page.html — a second static page, same route.
  • /web/ — proxy route: reverse-proxied to an independent whoami container elsewhere in this compose file. Reload it a few times; the hostname/IP it reports is the backend container, not the gateway.
  • /secret/ — the same kind of static route as this page, but with authentication.enabled: true. You'll be redirected to log in first.
  • /_/admin/ — the built-in admin dashboard (analytics, sessions, users, rate limiter stats, middleware status). Log in with the admin credentials from your .env.

Things that don't have a page to click

See this demo's README.md for curl examples of:

  • the rate limiter (repeated requests to /web/* start getting 429s)
  • CORS preflight response headers on /web/*
  • hot config reload — edit config.yaml on the host and it takes effect without restarting the container
